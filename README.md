# Комплект — модуль для 1С-Битрикс

Собственный модуль `komaroff.b2bassist`, версия 0.4.0. [Полный портал и инструкции](https://github.com/komaroffsergei/komplekt-b2b-portal) · [Демо](https://komplekt.komaroff-dev.ru/).

## Состав

- `QuoteEngine`: количество, цены в копейках, бюджет, остатки и срок КП.
- `PortalStore`: компании, роли, история КП, очередь, журнал и безопасные повторные отправки.
- `OneCClient` и `CatalogSync`: обмен с настоящей учебной 1С через локальный адаптер.
- `AiQuoteAgent`: ограниченный локальный AI-подбор с проверкой результата сервером.
- `QuotePdf`: PDF с кириллицей через Dompdf в окружении полного портала.

Модуль предназначен для хост-приложения «Комплект», а не является универсальным готовым решением Маркетплейса. В полном портале задаются `KOMPLEKT_SOURCE`, закрытые настройки адаптеров и зависимость `dompdf/dompdf`. Установка: `local/modules/komaroff.b2bassist`, регистрация модуля и создание его таблиц через `PortalStore::install()`.

```sh
php tests/quote_engine.php
```

Это 15 автономных проверок расчёта без ядра Битрикса. Остальные сценарии требуют установленной CMS и учебной 1С. Учебная отгрузка отмечается в портале, а не создаёт реальную поставку или документ отгрузки 1С.

Ядро CMS, лицензионные ключи, платформа 1С и реальные базы не распространяются с модулем. Для платформ нужны отдельные действующие права. Собственный код публикуется как авторский демонстрационный проект; лицензии сторонних зависимостей сохраняются отдельно.
